# Asv.Drones

Asv.Drones is a modular ground control station application for unmanned vehicles. Plugins extend the application without modifying its core.

## Guides

- [Getting started](getting-started.md): restore, build, and run the desktop application.
- [Development](development.md): project structure, package versions, and validation.
- [Documentation](documentation.md): edit Writerside topics and understand publication.

## Packages

The repository publishes [Asv.Drones](https://www.nuget.org/packages/Asv.Drones)
and [Asv.Drones.Api](https://www.nuget.org/packages/Asv.Drones.Api).
The application uses Asv.Avalonia for its user interface, Asv.Mavlink for MAVLink
communication, and Asv.Gnss for GNSS protocols.
